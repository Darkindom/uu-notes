# 小程序发布指南

## 一、环境配置

项目支持三种环境：

- **dev**: 开发环境（默认）
- **test**: 测试环境
- **prod**: 生产环境

### 1. 配置云环境 ID

编辑 `src/app.ts` 中的 `ENV_CONFIG`:

```typescript
const ENV_CONFIG = {
  dev: 'cloudbase-0gom0wo33480db9c',  // 当前开发环境
  test: 'cloudbase-xxx-test',          // 替换为测试环境 ID
  prod: 'cloudbase-xxx-prod',          // 替换为生产环境 ID
}
```

### 2. 创建云环境

在微信公众平台创建不同的云环境：

1. 登录 [微信公众平台](https://mp.weixin.qq.com)
2. 进入"开发" -> "开发管理" -> "开发设置" -> "云开发"
3. 创建新的云环境（建议命名：test、prod）
4. 获取云环境 ID，填入 `src/app.ts`

### 3. 为每个环境配置数据库

为 test 和 prod 环境分别创建数据库集合：

- `users`: 用户信息
- `babies`: 宝宝信息
- `records`: 记录信息

**集合权限设置**：
- 读权限：仅创建者可读写
- 写权限：仅创建者可读写

### 4. 部署云函数

为每个环境部署 `login` 云函数：

1. 打开微信开发者工具
2. 选择对应的云环境
3. 右键 `cloud/login` 文件夹
4. 选择"上传并部署：云端安装依赖"

## 二、编译命令

### 开发模式（带热更新）

```bash
# 开发环境（默认）
npm run dev:weapp

# 测试环境
npm run dev:weapp:test

# 生产环境
npm run dev:weapp:prod
```

### 生产构建

```bash
# 测试环境构建
npm run build:weapp:test

# 生产环境构建
npm run build:weapp:prod
```

## 三、发布流程

### 测试版发布

1. **构建测试版本**
   ```bash
   npm run build:weapp:test
   ```

2. **在微信开发者工具中**
   - 选择测试环境的云资源
   - 点击"上传"按钮
   - 填写版本号（如 1.0.0-test.1）和项目备注
   - 点击"上传"

3. **在微信公众平台**
   - 进入"开发管理" -> "开发版本"
   - 找到刚上传的版本
   - 点击"提交审核"（可选，用于体验版测试）
   - 或直接设置为"体验版"供内部测试

### 正式版发布

1. **构建生产版本**
   ```bash
   npm run build:weapp:prod
   ```

2. **在微信开发者工具中**
   - 选择生产环境的云资源
   - 点击"上传"按钮
   - 填写版本号（如 1.0.0）和项目备注
   - 点击"上传"

3. **在微信公众平台提交审核**
   - 进入"开发管理" -> "开发版本"
   - 找到刚上传的版本
   - 点击"提交审核"
   - 填写审核信息：
     - 功能描述
     - 测试账号（如需要）
     - 隐私协议
     - 用户数据使用说明
   - 提交后等待微信审核（通常 1-7 天）

4. **审核通过后发布**
   - 收到审核通过通知
   - 进入"版本管理" -> "审核版本"
   - 点击"提交发布"
   - 选择发布时间（立即发布或定时发布）
   - 确认发布

## 四、版本管理建议

### 版本号规范

采用语义化版本号：`主版本号.次版本号.修订号`

- **主版本号**：重大功能变更或不兼容的 API 修改
- **次版本号**：新增功能，向下兼容
- **修订号**：Bug 修复，向下兼容

示例：
- `1.0.0`: 首次正式发布
- `1.1.0`: 新增功能
- `1.1.1`: Bug 修复

测试版本可加后缀：
- `1.0.0-test.1`: 第一个测试版本
- `1.0.0-beta.1`: 第一个 Beta 版本

### 发布前检查清单

- [ ] 所有功能测试通过
- [ ] 数据库集合已创建并配置权限
- [ ] 云函数已部署
- [ ] 云环境 ID 配置正确
- [ ] 隐私协议和用户协议已完善
- [ ] 测试账号准备就绪（如需要）
- [ ] 小程序图标和名称已设置
- [ ] 小程序分类已选择
- [ ] 服务类目已配置

## 五、常见问题

### 1. 云函数调用失败

- 检查云环境 ID 是否正确
- 确认云函数已部署到当前环境
- 查看云函数日志排查错误

### 2. 数据库权限错误

- 确认数据库集合已创建
- 检查集合权限设置
- 确认用户已登录（有 openId）

### 3. 上传失败

- 检查小程序 appid 是否正确
- 确认当前微信号有上传权限
- 检查代码包大小（不能超过 2MB）

### 4. 审核被拒

常见原因：
- 功能描述不清晰
- 缺少必要的用户协议
- 涉及敏感内容未说明
- 测试账号无法登录

解决方法：
- 仔细阅读拒绝原因
- 完善相关文档和说明
- 提供可用的测试账号
- 重新提交审核

## 六、监控和维护

### 错误监控

在微信公众平台查看：
- 进入"运维中心" -> "错误日志"
- 查看用户反馈的错误
- 及时修复和发版

### 性能监控

- 查看页面加载时间
- 监控云函数调用耗时
- 优化数据库查询

### 用户反馈

- 定期查看"客服消息"
- 收集用户建议
- 优化用户体验

## 七、回滚方案

如果发现线上版本有严重问题：

1. **在微信公众平台**
   - 进入"版本管理" -> "线上版本"
   - 点击"版本回退"
   - 选择上一个稳定版本
   - 确认回退

2. **修复问题后**
   - 修复代码
   - 重新构建和上传
   - 提交审核
   - 发布新版本
