# UU Notes - 宝宝成长记录小程序

> 一个专为老人带娃设计的微信小程序，大字号、简单易用，记录宝宝的日常成长～

## 💡 项目初衷

因为家里的老人帮忙带娃，但市面上的小程序，功能复杂字号小，老人家看不清，所以想做一个专门给老人家带娃时，方便记录的小程序。

**设计理念**：
- 🔤 **大字号显示** - 老人看得清楚
- 🎯 **功能简单** - 只保留最常用的功能，不让老人困惑
- ⚡ **操作快速** - 两三步就能完成记录，不需要复杂操作
- 💾 **数据私有** - 部署在自己的 NAS 上，数据安全有保障

## ✨ 核心功能

### 📊 宝宝日常记录
- **喂养记录** 🍼 - 记录喂奶、喝水、辅食的时间和量
- **睡眠记录** 💤 - 记录宝宝睡觉和起床时间，自动计算睡眠时长
- **排便记录** 🚽 - 记录换尿布、大小便情况
- **体温记录** 🌡️ - 记录体温，方便观察宝宝健康状况

### 📈 成长跟踪
- **身高体重** 📏 - 定期记录宝宝的生长数据
- **成长里程碑** 🎉 - 记录宝宝第一次笑、第一次叫爸妈等重要时刻
- **照片记录** 📷 - 为每条记录添加照片（后续开发）

### 👨‍👩‍👧‍👦 多人协作
- **家庭共享** - 爸爸妈妈、爷爷奶奶都可以使用
- **多宝宝支持** - 可以同时管理多个宝宝的记录
- **记录人标识** - 清楚知道每条记录是谁添加的

## 🎨 界面特色

- ✅ **超大字体** - 字号比普通小程序大 1.5 倍以上
- ✅ **高对比度** - 黑白分明，色彩鲜艳，老人容易辨认
- ✅ **大按钮** - 按钮面积大，老人点击不容易出错
- ✅ **简洁布局** - 一屏只显示最重要的信息，不会眼花缭乱

## 🏗️ 技术架构

**前端（小程序）**：
- Taro 3.x - 跨端开发框架
- React + TypeScript
- 响应式设计，适配各种手机屏幕

**后端服务**：
- Node.js + Express
- SQLite 数据库
- JWT 认证
- RESTful API 设计

**部署方式**：
- 支持 Docker 一键部署
- 支持 NAS（群晖、威联通等）
- 资源占用极低（内存 < 50MB）

## 💰 为什么选择自建部署？

使用微信云开发 vs 自建在 NAS：

| 项目         | 微信云开发     | NAS 自建       |
| ------------ | -------------- | -------------- |
| 数据库       | ¥19.9/月起     | ¥0             |
| 云函数       | ¥0.0133/万次   | ¥0             |
| 存储         | ¥0.18/GB/月    | ¥0（NAS 容量） |
| **一年费用** | **~¥600-1200** | **¥0**         |
| 数据隐私     | 存在腾讯云上   | 完全自己掌控   |

对于家庭使用来说，自建在 NAS 上不仅节省成本，数据也更安全。

## 🚀 快速部署

本项目支持在 NAS（群晖、威联通等）或任何支持 Docker 的设备上部署。

### 一键启动

```bash
# 1. 克隆项目
git clone https://github.com/your-repo/uu-notes.git
cd uu-notes/server

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，修改 JWT_SECRET

# 3. 启动服务
docker-compose up -d
```
